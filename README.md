# Nourish Well

Build Prompt — Nutritional-Density.com

1. Project Overview

Build a modern, premium, educational health and wellness website called Nutritional Density.

Domain: Nutritional-density.com

The website should be an authoritative but approachable platform focused on:

Nutrition

Nutritional density

Healthy eating

Food education

Exercise and fitness

Health and wellness

Evidence-based lifestyle information

Practical nutrition guidance

Food comparisons

Macronutrients and micronutrients

Healthy recipes and meal ideas

Beginner-friendly fitness education

The website should feel like a combination of a modern nutrition publication, health education platform, and fitness knowledge hub.

The goal is NOT to make the website look like a generic fitness blog. It should feel clean, sophisticated, trustworthy, editorial, scientific, and modern.

2. Brand Identity

Brand Name

Nutritional Density

Use the brand name prominently in the website header and branding.

The brand should communicate:

Better understanding of food, nutrition, health, and fitness through simple, useful, evidence-based information.

Avoid making exaggerated health claims.

The website should prioritize education over selling.
